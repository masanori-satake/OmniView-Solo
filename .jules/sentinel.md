## 2026/03/31 - ログ一覧レンダリングにおける DOM 型 XSS の防止
**脆弱性:** `App.prototype.renderLogs` 内で `div.innerHTML` を直接使用してログメッセージを挿入していたため、カメラのカスタムラベルや外部インポートデータ、エラー詳細メッセージ等に悪意ある script / HTML タグが含まれている場合、DOM型 XSS (Cross-Site Scripting) や HTML インジェクションが実行される恐れがあった。
**学び:** `innerHTML` に文字列を結合・流し込む実装は、開発時に可読性が高く思えてもユーザー制御や外部データ入力が混入するリスクを伴う。
**予防策:** ログやメッセージなど文字列のみの表示箇所では `textContent` や `document.createTextNode()` を使用し、常に安全な DOM 構造構築パターンを適用する。

## 2026/04/02 - ストレージ移行および個別設定保存処理におけるプロトタイプ汚染の防止
**脆弱性:** `projects/app/js/camera.js` 内の `migrateSettings` および `saveCameraSetting` において、`chrome.storage.local` 由来のオブジェクト走査およびキー指定保存時にプロトタイプ汚染キー（`__proto__`, `constructor`, `prototype`）に対するバリデーションが欠落していた。これにより、ストレージデータに悪意のあるプロパティが含まれる場合や悪意あるデバイスIDが保存された場合にオブジェクトプロトタイプが汚染されるリスクが存在した。
**学び:** 外部インポート時だけでなく、拡張機能のストレージから読み込むデータや永続化処理のパラメータとしてキーを受け取る関数全般において、特殊キーに対するガード（排除・拒否）を徹底する必要がある。
**予防策:** オブジェクトキーを動的に走査・設定するすべての処理において、`__proto__`, `constructor`, `prototype` キーの存在チェックおよび除外を必須とする。

## 2026/04/01 - カメラ情報表示の DOM 型 XSS 防止と JSON 設定インポート時のプロトタイプ汚染防止
**脆弱性:** `displayCameraInfo` において `innerHTML` を用いてデバイス設定値等をレンダリングしていたため、カメラプロパティやキャッシュに HTML タグが含まれる場合の DOM 型 XSS リスクが存在した。また、設定ファイルインポート時にオブジェクト型チェックの欠落および `__proto__` キーの未フィルタリングによりプロトタイプ汚染のリスクが存在した。
**学び:** Web API 由来の動的プロパティや外部ファイル由来の JSON は、予期せぬ文字列や特殊キーを含み得るため、表示時は `textContent` による安全なノード構築を行い、オブジェクト走査時はプロトタイプ拡張用キー（`__proto__`, `constructor`, `prototype`）の明示的排除が必要である。
**予防策:** 動的な文字列描画には `textContent` を徹底し、外部 JSON の取り込み時には型チェックとプロトタイプ汚染キーのブロック処理を適用する。
