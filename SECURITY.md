# Security Policy

## Supported Versions

Currently, only the latest version of OmniView-Solo is supported.

| Version | Supported          |
| ------- | ------------------ |
| v0.1.x  | :white_check_mark: |

## Reporting a Vulnerability

Please report any security vulnerabilities by opening an issue on GitHub.
As this is a local-only extension, the risk is limited to local data exposure within the browser.
